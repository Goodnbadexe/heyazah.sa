# Media placement audit

This note keeps the alpha rule explicit: do not place live website text over a video or image that already contains baked-in text, logos, project names, or UI.

## Video findings

- `hero-loop.mp4`: contains Heyazah logo/brand text and project collage moments. Use as a dedicated media zone, not as a text-backed hero background.
- `orbit-showcase.mp4`: contains large text such as "Founded 2005" and portfolio copy. Use as a standalone showcase panel only.
- `projects-reel.mp4`: contains large project names and arrows. Use as a standalone ribbon/panel only.
- `search-preview.mp4`: contains a search UI and typed text. Do not use behind live search UI.
- `entrance.mp4`: can remain in the optional intro because the intro copy is centered outside the main site flow and the video is object-contained.

## Placement rules

1. If media has baked-in text, it must sit in its own frame or media zone.
2. Live headings and buttons should sit on solid brand color, plain paper, or media confirmed to be text-free.
3. When adding new video assets, extract representative frames before using them as backgrounds.
4. Background video is allowed only when the frame is mostly architectural imagery with no readable embedded text in the live-copy area.
