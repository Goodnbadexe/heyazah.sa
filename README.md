# Heyazah.sa

Alpha website and WordPress migration workspace for Heyazah.

## Apps

- `apps/web` — Next.js alpha website.
- `apps/wp-theme` — WordPress FSE theme and importer packages.
- `migration` — migration data, tokens, reports, and project JSON.

## Current Verification

- `npm run build` passes in `apps/web`.
- Homepage, search modal, and showcase sections were checked with Playwright.
