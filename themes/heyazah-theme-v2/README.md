# Heyazah Pro - WordPress Block Theme

A professional, fully-featured Block Theme designed for Heyazah Real Estate (شركة حيازة العقارية), a Saudi Arabian real estate development company.

## Features

- **Full RTL Support**: Complete Arabic and English language support with proper RTL styling
- **Block Theme**: Built on WordPress 6.3+ block infrastructure
- **Custom Post Types**: Project, Unit, and Media Center post types with taxonomies
- **Responsive Design**: Mobile-first approach with full responsive support
- **Google Fonts Integration**: Readex Pro font family supporting Arabic and English
- **Advanced Color Palette**: Brand-aligned color scheme with primary teal, beige, gold, and dark accents
- **Block Patterns**: 6 pre-built patterns for quick content creation
- **Custom Templates**: Specialized templates for homepage, projects, archives, and more
- **Accessibility**: WCAG 2.1 AA compliant with proper semantic HTML
- **SEO Optimized**: Proper heading hierarchy and semantic markup
- **Plugin Compatibility**: Works with ACF, Rank Math SEO, Contact Form 7, qTranslate-XT

## Installation

1. Upload the `heyazah-theme-v2` folder to `/wp-content/themes/`
2. Go to WordPress Admin > Appearance > Themes
3. Find "Heyazah Pro" and click "Activate"
4. Go to Appearance > Editor to customize

## Custom Post Types

### Projects
- Slug: `project`
- Supports: Title, Editor, Thumbnail, Excerpt, Custom Fields
- Taxonomies: Project Category, Project Status, Sector

### Units
- Slug: `unit`
- Supports: Title, Editor, Thumbnail, Excerpt, Custom Fields
- Taxonomies: Unit Status, Sector

### Media Center
- Slug: `media_center`
- Supports: Title, Editor, Thumbnail, Excerpt, Custom Fields
- Taxonomies: Media Type

## Quick Setup Guide

1. **Upload Logo**
   - Go to Appearance > Site Identity
   - Upload your company logo (supports SVG)

2. **Create Navigation Menus**
   - Go to Appearance > Menus
   - Create "Primary Menu" with pages/links
   - Assign it to "Primary Menu" location

3. **Configure Theme Colors**
   - Go to Appearance > Editor (Experimental)
   - Customize colors in the Site Editor

4. **Create Content**
   - Start creating posts using the Block Editor
   - Use block patterns for quick layouts
